## ⚠️ Troubleshooting

### Problema: Copilot não funciona
**Solução:**
1. Fazer login com GitHub
2. Verificar extensão instalada
3. `flutter clean && flutter pub get`

### Problema: Google AI Key inválida
**Solução:**
1. Gerar nova key em aistudio.google.com
2. Validar formato em .env
3. Verificar rate limits

### Problema: Supabase desconectado
**Solução:**
1. Verificar URL do Supabase
2. Validar anon key
3. Verificar conexão internet
